# Extensions that should open in the editor (see file-associations.sh).
#
# One extension per line, no leading dot. Blank lines and #-comments ignored.
# Order is irrelevant; grouping is for humans reading the diff.
#
# Before adding a line, check what the extension actually resolves to:
#
#   bash scripts/macos/file-associations.sh check <ext>
#
# macOS binds handlers to UTIs, not to extensions, and several developer
# extensions are squatted on by an unrelated media or document type. Binding
# those steals the real file type too. The deliberate exclusions are listed at
# the bottom of this file - read them before "fixing" a missing extension.

# --- deliberately NOT bound --------------------------------------------------
#
# Each of these is a real developer extension that is ALSO the extension of an
# unrelated file type macOS already handles correctly. Binding the editor to
# the UTI would hijack the other type, because the binding is per-UTI and the
# UTI is the other type's.
#
#   key    Keynote presentation (com.apple.iwork.keynote.sffkey), not an SSH key
#   pub    MS Publisher document, not an SSH public key
#   exs    Logic/GarageBand sampler instrument, not Elixir script
#   fs     GLSL fragment shader (org.khronos.glsl.fragment-shader), not F#
#   r      Rez source (com.apple.rez-source), not R
#   cue    Audio cue sheet (VLC), not CUE lang
#   scpt   Compiled AppleScript - a binary; Script Editor must open it
#   wasm   Binary
#   srt    Subtitles - VLC
#   ass    Subtitles - VLC
#   vtt    Subtitles - VLC
#
# html, htm and xhtml are excluded by preference, not by collision: double-
# clicking an .html file previews it in the browser, which is usually what is
# wanted. Add them here if that changes.

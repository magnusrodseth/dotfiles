A message that leaves this machine in Magnus's name goes out only after he
approves that exact text. This covers email, Slack, LinkedIn, iMessage,
Vibbo, GitHub comments to people outside his own repos, and any reply or
forward.

1. Load the `write-in-my-voice` skill before you write the first word, for
   every draft in his name: a new message, a reply in a thread, or a rewrite.
   It sets the language, the register, and whether to greet.
2. Write the full draft inline in your chat reply: recipient, subject, and the
   complete body as it will be sent. A file path, a Gmail draft id or a
   summary is not a draft he can read.
3. Stop and wait. Any clear go-ahead on the current text is approval: "send",
   "yes", "ja", "go", "dette går fint å sende", or the same as a comment on
   the draft. Approval of an earlier version does not carry over. Any edit
   restarts the cycle with the new full text.
4. After approval, send that text unchanged and report what went out. Do not
   ask him to repeat the approval with a specific word.

Saving a draft in Gmail is fine without asking; say that it is a draft and
that nothing was sent.

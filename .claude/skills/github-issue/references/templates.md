# Issue templates

Use local issue forms and domain terms when present.

| Kind | Required content |
|---|---|
| Idea | Problem, affected user, desired value, unknowns and decision owner |
| Decision | Precise question, evidence, options, constraints and named decision owner |
| Bug | Reproduction, expected/actual behavior, environment/version and observable acceptance criteria |
| Implementation | Chosen outcome, current/desired behavior, scope, acceptance criteria and relevant verified interfaces |
| Maintenance | Concrete debt/risk, proposed change, affected manifests and verification |
| Epic | Goal, scope, native child issues, live blockers and completion criteria |

Reference inspected code when useful. Preserve the original request and any
unresolved requirements when consolidating. An investigation's factual answer
does not stand in for a human product decision.
